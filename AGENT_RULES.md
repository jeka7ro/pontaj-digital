# REGULI STRICTE PENTRU AGENT (OBLIGATORIU DE CITIT LA FIECARE SESIUNE)

1. **FOLDERUL DE LUCRU EXCLUSIV**: 
   Agentul are voie să lucreze, să caute, să vizualizeze și să modifice fișiere **DOAR** în folderul curent (rădăcina proiectului deschis în IDE, acolo unde se află acest fișier).

2. **INTERZIS ÎN ALTE FOLDERE**:
   ESTE STRICT INTERZISĂ accesarea (citire/scriere/rulare comenzi) oricărui director aflat mai sus în ierarhie (părinte) sau în alte proiecte învecinate. Dacă metadatele editorului menționează alte foldere, acestea vor fi ignorate. Uită de orice altceva din exterior.

3. **WORKFLOW LOCAL**:
   - Verificările se fac pe `localhost`.
   - Modificările de cod se salvează doar în acest folder.
   - Comenzile Git se aplică strict pe repository-ul curent.

4. **FĂRĂ PUSH FĂRĂ APROBARE EXPLICITĂ (REGULĂ CRITICĂ)**:
   Sub nicio formă și sub nicio scuză nu vei executa `git push` sau force push către servere remote (ex: `origin/main`) fără un "DA" absolut explicit și clar din partea utilizatorului. Indiferent de context, cere voie și așteaptă confirmarea finală înainte de orice acțiune ireversibilă de push.

Dacă ai înțeles asta, rezolvă problemele fără să pui întrebări inutile.
